FAQ
问题：SN65HVD230 CAN Board 这个最高速率支持多少?
最高支持1Mbps



问题：默认有焊接120欧姆电阻么?
有焊接，打字 121 靠近CAN 接口的电阻就是 120欧姆电阻，如果需要去掉，请焊接去掉。



问题：can接收器有没有txd接受5.5v电压的?
模块工作电压和逻辑电平都是3.3V
不能直接用 5.5 V 驱动 TXD，否则可能损坏芯片



问题：买了别家的开发板能用么？
前提是该主板得有 CAN TTL 数字接口才可以使用SN65HVD230 CAN Board, SN65HVD230 CAN Board 是can收发器，纯硬件接口转换板，功能非常专一的
