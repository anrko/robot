# 轮腿机器人软核平衡控制框架

目录保存运行在当前 Murax/VexRiscv 融合工程上的平衡控制骨架。它沿用现有 `RobotApb` MMIO，不需要修改 FPGA 位流即可继续扩展软件控制。

当前版本的安全行为：

- 上电状态为 `SAFE`，不会自动使能 DM4310，也不会发送非零轮电流。
- 1 kHz 定时器中断每拍只提交一个 CAN 帧，五拍轮换一次：C620 零电流、DM1、DM2、DM3、DM4。这样避免在中断里等待 CAN 总线。
- DM 反馈已经解析为位置、速度、力矩、状态和新鲜度；C620 反馈已经解析为编码器角度、RPM、电流和温度。
- `BALANCE_IMU_STUB=1`，姿态输入暂时固定为无效；因此串口输入 `a` 会被拒绝，不能误使能电机。
- `BALANCE_OUTPUT_ENABLE=0`，即使将 IMU 占位关闭，控制输出仍需显式打开。
- `q` 只在失能且四个 DM、两个 C620 都有新反馈时，把当前姿态保存为 RAM 中的站立参考；它不会把机械限位写进电机参数。

## 软核程序结构

`main.c` 分成五层：

1. `sample_feedback()`：从 RobotApb 读取 DM4310/C620 反馈。
2. `sample_imu()`：预留 BMI088 轴向、符号和量程换算。
3. `balance_compute()`：预留机身俯仰控制、腿部运动学、VMC/LQR 和限幅。
4. `send_active_slot()`：统一打包 DM4310 MIT 帧和 C620 `0x200` 组电流帧。
5. `control_tick()`：安全状态机、超时保护和周期调度。

状态命令：

| 按键 | 作用 |
|---|---|
| `s` | 打印状态、IMU 有效位、反馈新鲜度和四个 DM 角度 |
| `q` | 在 SAFE 且反馈新鲜时保存当前站立参考 |
| `a` | 请求进入 ARMING；当前 IMU 占位会拒绝此操作 |
| `d` | 请求失能，依次发送 DM 失能帧和 C620 零电流 |

构建命令：

```powershell
python .\softcore_apps\balance_control\build_balance_control.py
```

通过 SecureCRT 的 **Transfer -> Send Binary File...** 发送生成的 `build\balance_control_frame.bin`。这只是 CPU 应用镜像；修改 `RobotApb.v`、CAN 过滤器或引脚后仍需重新综合 FPGA 位流。

## 真正闭环前缺少的数据

### 必须现场确认

- BMI088 安装方向：机身前方、右方、上方分别对应哪一个传感器轴；`pitch` 的正方向；陀螺仪角速度量程和原始值到 °/s 的换算。
- 四个 DM ID 对应的物理关节：用户已确认 `SOLID`/`SOLID001`/`SOLID002`/`SOLID003` 分别为 ID1/2/3/4；仍需给 `+Z` 指定前后名称，并在实物上确认每个关节的角度正方向。
- 四个关节的正方向。应在失能状态下逐个小幅手动移动，记录角度增量符号。
- 实际站立姿态角，不能使用最高/最低机械限位作为闭环目标；应在限位内侧留出裕量。
- M3508 承载有效轮半径、C620/电机减速比的实测核对、轮子正方向，以及 `current_raw` 到实际电流/力矩的换算。当前只有名义半径 62.5 mm 和资料减速比 19.2032:1。
- 轮腿 CAD 的关节轴线关系、轮心高度、允许腿长范围和关节角到腿长的运动学映射。当前已读取 LINK 孔距 140.0 mm、LEG 两端孔距 72.5 mm。
- 机身、腿、轮子的质量和重心位置；这些用于初始 LQR/VMC 增益。
- DM4310 的通信超时保护值。当前参数为 0，不能把它当成已验证的失联保护。
- 急停方式和电机电源切断方式。

### 软件仍需补充

- BMI088 零偏校准和 `sample_imu()` 的轴/比例转换。
- 关节角到腿长、腿角及导数的正/逆运动学。
- 俯仰平衡的轮力矩控制器，以及 VMC 雅可比到四个 DM 力矩的变换。
- M3508 左右轮符号、轮速闭环和电流限幅。
- 使能确认、通信丢失超时、姿态超限和温度超限时的硬失能路径。
- 离线 Python 模型：先用采集的 IMU/DM/C620 CSV 调整符号和增益，再把同一组定点公式移入 `balance_compute()`。

在这些数据确定前，框架只用于采集和验证输入，不能把 `BALANCE_OUTPUT_ENABLE` 改为 1 后直接让机器人落地运行。

## 已确认的执行器参数

### C620/M3508

- M3508 减速比为 `3591/187 = 19.2032:1`，常写作 19:1；C620 反馈的 rpm 是转子侧转速。
- 当前仿真工程引用的轮半径为 `0.0603 m`，只能作为参考，必须用当前轮胎外径实测替换。
- C620 的 `0x200` 控制帧中，每个电机槽位是有符号 16 位电流指令，`-16384..16384` 对应约 `-20..20 A`。
- M3508 资料给出额定转矩 `3 N·m`、额定电流 `10 A`、转矩常数约 `0.3 N·m/A`；C620 的持续允许电流为 `20 A`。平衡控制初始限值应优先按 M3508 额定值，并留出温升余量。
- 参考换算：`wheel_rpm = rotor_rpm / 19.2032`，`v = 2π R wheel_rpm / 60`，`I_A ≈ current_raw*20/16384`。左右电机的车体正方向必须架空实测后设置符号。
- 当前接线保持：C620 ID1 对应右轮 `R_M3508`，ID2 对应左轮 `L_M3508`；未使用的 `0x200` 槽位保持零。

### DM4310-2EC

- 手册 24 V 参数：额定相/电源电流 `4.9/3.1 A`，峰值相/电源电流 `20/16.5 A`，额定/峰值力矩 `3.5/12.5 N·m`，减速比 `10:1`。
- 当前 `PMAX=12.5`、`VMAX=30`、`TMAX=10` 是 MIT 的映射范围，不代表连续安全输出。软件还必须设置更低的力矩、速度和温度限幅。
- `TIMEOUT(0x09)` 的一个计数周期是 `50 μs`，只在使能时生效；当前四台读到 `0`，其固件语义尚未通过实验确认，不能视为已启用失联保护。正式测试要先配置非零值，再停止发送验证反馈状态和实际失能行为。
- 当前反馈状态使用 `Master ID=0`，电机 ID 在 D0 低四位，状态在高四位；`0` 为失能、`1` 为使能、`D` 为通信丢失。
- 位置解析需再核对：当前程序按 `PMAX=12.5` 将 16 位位置字段映射为 `[-12.5,+12.5] rad`，而手册写明上电后位置输出限定为 `[-π,+π] rad`。已有记录中出现 `-4.461` 和 `3.943 rad`，闭环前应重新读取原始字段并查询 `0x50 (p_m)`、`0x51 (xout)`，确认实际变量后再使用关节角。

## 先让执行器动起来的最小条件

在整机平衡之前，可以先做“架空、低功率、单电机、可立即断电”的动作验证。还缺的不是更多 CAD 名称，而是以下运行条件：

1. **电气安全**：确认电池/电源电压在 DM4310、C620 和 M3508 的允许范围内，CAN 两端终端电阻、共地、急停和电机电源切断均可用；电源应有保险或限流。
2. **DM 单电机测试**：确认使能/失能报文实际生效；把四台 `TIMEOUT` 从当前读值 0 的状态变成已验证的非零保护，随后逐台发送极小 MIT 力矩或位置命令，记录角度变化方向和反馈状态。
3. **轮电机测试**：架空左右轮，分别给 CAN1 ID1/ID2 很小的正、负电流，记录 rpm 符号、轮胎实际旋向和是否有异常发热；把结果写入左右轮符号表。
4. **软件开关**：当前 `BALANCE_IMU_STUB=1`、`BALANCE_OUTPUT_ENABLE=0`、`balance_compute()` 仍为占位，程序不会驱动机器人。完成上述单电机测试后，才可以在支架上逐步实现控制输出和限幅。

## 让整机保持平衡还必须补齐

- IMU 装到机器人后的轴向、静止零偏、直立 pitch 零点和前后倾斜符号；
- 站立姿态下四个 DM 的目标角（避开机械限位），以及 DM 角度字段和几何关节角的零点/回绕换算；
- 关节角到腿长、腿角及速度的正/逆运动学；
- 承载有效轮半径、左右轮速度符号和轮速闭环；
- 整机质量、重心高度/前后位置及初始惯量估计；
- 姿态、关节、轮速、温度、电流和通信失联的限幅/失能策略；
- 防倒支架、急停和逐级增加力矩的调试流程。
