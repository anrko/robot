已按“独立 Python 浮点参考 → RTL 对比 → 接入 OSD”完成第一阶段。采用六轴 Madgwick，保留原 MQFU 作为问题复现样本，生产数据通路重整为 Q8.24。没有使用软核 CPU。

## 验证结果

| 检查 | 数据量 | 结果 |
|---|---:|---|
| 独立核心，RTL 对比 Python 浮点四元数 | 11 类场景，16,200 组 | 最大旋转差异 0.045653°，阈值 0.25° |
| 四元数转 Euler、符号和 BCD | 16,850 组 | 最大角度差异 0.050050°，阈值 0.11° |
| 整数开方、归一化 | 188 组，含 signed 32-bit 边界 | 与 Python `math.isqrt` / 整数除法逐位一致 |
| 跨时钟域、整帧锁存 | 异步时钟，连续更新、目的时钟停止及复位 | 通过；帧内显示字段保持稳定 |
| ROM → 解算 → Euler → BCD → CDC → OSD | 2,048 组，两个 ROM 周期 | 最大 RTL/浮点旋转差异 0.215038°；显示差异 0.186445°；分别低于 0.35°、0.4°阈值 |
| 原仓库默认参数诊断 | 16 组 | 重现输入 1 rad/s Z 轴角速度而四元数不更新的问题；该原核不参与综合 |

独立核心使用约 500 Hz 的周期，同时覆盖 1–4 ms 可变周期；演示 ROM 是 100 Hz，因此两项误差不能混为同一采样条件。所有阈值在各自仿真运行前声明。

浮点模型和 RTL 使用相同的量化采样值、相同 dt、beta 与零梯度阈值。参考模型用 Hamilton 四元数乘法、独立 Jacobian 和标准浮点开方；不使用原仓库的定点 Python 模型。四元数误差按相对旋转角计算，考虑 q 与 -q 等价，而非直接减四个分量。

另用解析四元数指数积分产生无噪声旋转真值，检查正反方向、多轴耦合、静态倾斜收敛。静态六轴倾斜仅验收 Roll/Pitch；Yaw 没有绝对参考，不能按生成数据的绝对航向验收。

逐项机器可读结果、源码 SHA256 和最终位流哈希见 [validation_summary.json](validation_summary.json)。误差图见 [comparison.png](comparison.png)。完整原始 CSV 会在本地 `sim/imu/results/` 生成。

## 构建与烧录

目标器件：**GW5AT-LV60PG484AC1/I0**，使用 Gowin V1.9.12.03。

- 原占位显示配置：`release/camera720_cam2_720p.fs`，来自 OSD 检查点。
- 新解算演示配置：**`release/camera720_cam2_720p_imu_demo.fs`**。
- 可独立解压重建的源码包：`release/camera720_imu_demo_project.zip`。
- 演示工程：`camera720_imu_demo.gprj`，顶层 `top_camera720_imu_demo`。

连接方式、网口地址及 RK3588 接收程序沿用原摄像头工程。用 Gowin Programmer 选择新的 `..._imu_demo.fs`，先通过 JTAG 临时加载。画面左上角应显示 **IMU / DEMO**，三路角度周期变化。它使用模拟加速度和角速度经过实际 FPGA 解算，不是预存角度直接显示。

重建：

```powershell
& 'F:\GOWIN\Gowin_V1.9.12.03_x64\IDE\bin\gw_sh.exe' tools/build_camera720_imu_demo.tcl
```

本次还修正了 125 MHz UDP / 发送状态机的异步复位释放：异步置位、三个本域时钟后释放。时序例外只针对复位同步器自身的 PRESET 引脚；同步器输出到功能寄存器的复位路径继续检查。约束语法根据 [Gowin SUG940 时序约束手册](https://cdn.gowinsemi.com.cn/SUG940E.pdf) 第 5.4.1 节核对。

最终资源、各时钟 Fmax 和 setup/hold 检查计数保存在 `validation_summary.json`，完整工具报告见 [gowin_timing.html](gowin_timing.html) 与 [gowin_resources.txt](gowin_resources.txt)。打包脚本会拒绝归档仍有时序违例或 Fmax 不达标的版本。

仍保留工具 PR1014 提示：`clk50m_d` 使用普通布线资源作时钟。当前板外 IO 延时约束沿用摄像头工程，不能用综合成功代替上板检查。

## 复现测试

```powershell
python tools/imu/validate_all.py
```

需要 Python + NumPy + Matplotlib + Icarus Verilog。可分别运行 `validate.py`、`validate_euler.py`、`validate_math.py`、`validate_demo.py` 排查。

## BMI088 接入边界

本阶段已经完成解算与 OSD 数据通路，**尚未添加 BMI088 的 SPI/I²C 采集驱动和物理引脚**。外设到货、确定接线后，用采集模块替换 `imu_demo_source`，完成量程换算、静止零偏标定、坐标轴变换和采样时间戳，再接入 `attitude_pipeline`。

模拟数据证明的是所测条件下的数值实现和数据传输正确性，不代表实际 BMI088 能达到同样的绝对角度精度，也不代表轮腿机器人已能连续稳定运行一小时。振动、加减速、零偏、安装方向和控制器调试仍需要实机验证；六轴 Yaw 仍会漂移。
