# 执行器诊断与装配几何记录

## 侧面与坐标约定

2026-10-12 用户确认：DM4310 的 `SOLID`、`SOLID001`、`SOLID002`、`SOLID003` 分别为 CAN0 ID1、ID2、ID3、ID4；`R_M3508` 为 CAN1/C620 ID1，`L_M3508` 为 CAN1/C620 ID2。CAD 坐标约定为 `X=左右、Y=上下、Z=前后`，其中 `+X` 为右侧、`-X` 为左侧。截图上方对应前方还是后方仍需在机器人上指定。编号映射已确认，但每个电机的旋转正方向、机械零位和控制角符号仍需小幅动作实测。

## 从 `R6R4_D03_assembly.FCStd` 读取到的内容

装配文件内部元数据确认：

- 顶板 `R6R4_TOP_DECK`：`144 × 136 × 3 mm`。
- 左右轮胎/轮辋部件标注为 `5X20001`、`5X20002`；CAD 名义外径约 `125 mm`，名义半径 `62.5 mm`。
- 左右 M3508 实体装配插入原点分别约为 `(-14.059,-40.268,+1.789) mm` 和 `(+14.059,-40.268,-1.789) mm`；它们是模型原点，不等同于轮心或编码器零位。
- 主转轴 `R6R2_L/R_PIVOT6804` 轴心约为 `(-109.75,-22,0)` 和 `(+109.75,-22,0) mm`，轴线沿 X。
- `R6R2_L/R_LINK100`、`LINK200` 两端圆孔中心距均为 `140.0 mm`。
- `R6_L/R_LEG300_HIGH`、`LEG400_HIGH_CLOUD` 两端圆孔中心距均为 `72.5 mm`。
- 四个 DM CAD 象限为：ID1=`SOLID`（`+X,+Z`）、ID2=`SOLID001`（`+X,-Z`）、ID3=`SOLID002`（`-X,-Z`）、ID4=`SOLID003`（`-X,+Z`）。

以上几何值由 FreeCAD 1.1.4 的 `Part` 几何直接读取，未修改原始 FCStd。轮胎承载有效半径、关节机械零位、质量/重心和电机正方向仍不能由 CAD 单独确定。

用户提供的实物轮胎为 RISING SUN `5x2A`，标称外径 `125 mm`、未承载半径 `0.0625 m`、宽度 `40 mm`、内径 `92 mm`、单条 `0.17 kg`。需测承载有效半径后用于轮速换算。旧仿真资料中的轮胎半径 `0.0603 m` 和其它 VMC 参数不能覆盖上面已经读取的 D03 CAD 几何值。

## 质量和重心是否要现在测

写采集程序、读 BMI088/CAN、确认电机方向和构建安全状态机都不需要精确质量/重心。可以继续推进这些工作。

真正进入自平衡控制后，质量、重心高度和机体转动惯量会影响模型、控制器增益、腿部支撑力与力矩限幅。它们不是开始写控制器代码的门槛，但不能长期当作零或套用其他机器人的值。建议先用 CAD/BOM 和已知电池、电机质量做一版粗估，并给出误差范围；加装件确定后用秤测整机重量。重心可先按各组件质量和 CAD 位置估算，之后在支架上通过不同支点的秤重或倾斜静态实验校准。采用现场小增益调试也仍需保守的重量和力矩上限。

## 诊断镜像

应用在 `softcore_apps/actuator_diag`。开机不发使能/非零命令。`q` 读取四个 DM 的 Imax (`0x3B`) 和 TIMEOUT (`0x09`)；当前测试程序把 `TIMEOUT>=400`（20 ms）设为自定义软件门槛，并不会写入参数。达妙手册说明 TIMEOUT 以 50 μs 为周期、只在使能时生效；手册没有解释读值 0 在驱动器固件里的特殊行为，因此 `0` 不能当作“没有使能”，也不能当作已验证的失联保护。实际启用 DM 前先确认 0 的行为、配置非零保护并验证。C620 单次方向测试为约 0.244 A、100 ms，随后发送零电流帧。

具体按键与烧录步骤见 [`softcore_apps/actuator_diag/README.md`](../../softcore_apps/actuator_diag/README.md)。
