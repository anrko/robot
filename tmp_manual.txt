前 言
     ACG138 是一块采用“核心板 + 底板”分体式架构的异构计算开发板。核心板以瑞芯微 RK3588
为主控，并板载一颗国产高云（GOWIN）GW5AT-60K 系列 FPGA，二者之间通过 PCIe 3.0 ×2、
RGMII 千兆以太网、I2C7 与 FSPI 四条片间链路互联（其中 FSPI 与板载 eMMC 复用 RK3588 的同
一组控制器引脚，通过 0 Ω 电阻分选）；底板则把 RK3588 的多媒体、高速接口资源与 FPGA 的可
编程 IO 资源全部引出，并提供 FMC LPC、LVDS 排针、MIPI、SFP、M.2、PCIe 等扩展能力。

     与所有资源都围绕单一器件展开的传统开发板不同，ACG138 的价值在于“两条腿走路”：

•   RK3588 侧提供成熟的操作系统生态（Android / Linux / Debian）、强大的 CPU/GPU/NPU 算力，
    以及 HDMI、MIPI、USB3、SATA、PCIe、千兆网等标准接口；
•   GW5AT-60K 侧提供完全可编程的 IO 与硬核收发器，配合 512MB DDR3L 缓存，适合做高速数
    据采集、协议桥接、视频预处理、接口转换等处理器不擅长的工作；
•   两者通过片间 PCIe 、RGMII 与 I2C7 协同，可以把 FPGA 采集的数据直接高速送入 RK3588 处
    理或显示。

     本文档面向使用 ACG138 进行二次开发的硬件工程师、FPGA 工程师与嵌入式软件工程师，目
标是让读者在不翻阅原理图的前提下，快速掌握开发板的外形结构、供电方式、每一个连接器的引
脚定义以及各接口的信号来源。文档共分为五个部分：

•   【第一部分】快速上手 —— 从插线供电到串口登录的最短路径；
•   【第二部分】硬件资源详解 —— 逐项说明板载器件与接口；
•   【第三部分】系统启动与默认系统 —— 启动介质选择与控制台使用；
•   【第四部分】开发与调试 —— FPGA 与 SoC 两侧的工具链和固化方法；
•   【第五部分】接口引脚定义总表 —— 全部连接器的逐引脚定义与核心板-底板连接器对照表。


    【阅读建议】本手册配套资料包括：底板与核心板原理图（PDF）、装配图、网表文件（.NET）
    以及本手册。建议将本手册与原理图对照阅读。

第一步：认识 ACG138

    ACG138 由两块印制板通过 6 个 100pin 板对板连接器（共 600pin）对插组成：

•   核心板（丝印 RK3588+GW5AT-60K，料号 26082801）—— 板载 RK3588 主控、GW5AT-60K
    FPGA、2GB LPDDR4X、8GB eMMC、512MB FPGA 专用 DDR3L、128Mb 配置 Flash 与全套
    电源管理电路；
•   底板（丝印 ACG138-RK3588-CB，料号 26090801）—— 承载全部对外接口、扩展连接器与调
    试电路。
    两块板卡的尺寸不同，核心板四周各有 1 个 φ4mm 安装孔，底板四角同样各有 1 个 φ4mm 安
装孔（位号 E1~E4）。实际装配时，应先用连接器对插定位，再通过安装孔固定，避免单侧受力导
致连接器损伤。

第二步：给开发板供电

    ACG138 采用单路 12V 直流供电，板载 DC-DC 将 12V 降压为 5V 主电源，再由核心板上的
PMIC 及其配套电路生成各电压域。供电入口位于底板右下角。

•   电源接口：DC1，标准 DC-002 圆孔插座（内正外负）；
•   输入电压：12V（板上有 SMCJ15CA 瞬态抑制二极管与 F1/F2/F3 保险丝做输入防护）；
•   电源开关：S1（3 脚拨动开关），位于 DC1 上方，丝印 ON / OFF；
•   5V 主域额定电流：经 F4（3A）保险丝后提供给 VCC5V0_SYS。




                图 1-3 DC1 电源输入与 S1 电源开关（丝印 12V / OFF / ON）


     上电顺序建议：

•   先将 S1 拨到 OFF 位置（靠近丝印 OFF 一侧）；
•   把 12V 电源适配器插入 DC1，确认适配器极性正确；
•   将 S1 拨到 ON 位置，底板上的电源指示灯点亮；
•   断电时先拨回 OFF，再拔出适配器。

    【警告】请勿使用劣质或电压不符的电源适配器。输入电压超标会直接损坏 12V 域电路；如果使
    用外接稳压电源，务必确认内正外负且电压为 12V。

     ACG138 支持 12V 供电的同时通过 USB_Debug 口连接 PC，用于供电、调试串口与 FPGA 下
载：

第三步：连接调试线缆

    ACG138 把调试功能集中在一个 Type-C 口上，即底板右上角的 USB_Debug 接口（J2）。该口
内部连接一颗 USB Hub（SL2.1S），向下扩展出三路 USB 设备：

•   CH9102F（U45）—— RK3588 侧调试串口；
•   CH340E（U15）—— FPGA 侧调试串口；
•   板上 USB-JTAG 下载器（U13，JTAG18M02HS2）—— 通过 USB 完成 FPGA 的 JTAG 配置与
    在线调试。
    因此，用一根 Type-C 数据线把 PC 与 J2 相连，就同时获得了“两个串口 + 一个下载器”，无需
外接任何下载器。




                     图 1-5 USB_Debug 接口（J2）及周边电路实拍

      SWD 调试      P9        1×4 排针（1.27mm）   SWCLK / SWDIO，用于调试板载下载器 MCU 或外

第四步：安装驱动程序

     ACG138 在 PC 侧需要三类驱动：RK3588 侧串口芯片 CH9102F 与 FPGA 侧串口芯片 CH340E
的 USB 转串口驱动，以及 USB-JTAG 下载器驱动。多数情况下 Windows 10 / 11 会自动识别并安装
串口驱动。

•    串口驱动：按所用芯片型号安装沁恒（WCH）官方驱动后，设备管理器的“端口（COM 和
     LPT）”下会出现两个 COM 口，分别对应 RK3588 串口（CH9102F）与 FPGA 串口（CH340E）；
•    USB-JTAG 驱动：按照所用 FPGA 工具链（Gowin Programmer）提示安装，或直接使用 Gowin
     EDA 安装目录下的驱动安装程序。




          图 1-6 J2（USB_Debug）在设备管理器中的枚举结果：USB Hub 下挂两路 USB 转串口设备


     驱动安装完成后，建议记录两个 COM 口的编号（例如 COM71 对应 RK3588、COM67 对应
FPGA），后续串口终端与下载工具都要用到。
第五步：上电与串口登录

     串口参数：数据位 8、无校验、停止位 1、无流控。波特率需与固件配置一致：RK3588 侧常见
为 1500000，FPGA 侧常见为 115200，请以实际出厂固件为准。

     操作步骤：

•   按第二步给开发板上电，并将 USB_Debug 接入 PC；
•   打开串口终端（SecureCRT、MobaXterm、PuTTY 或 minicom 均可），选择 RK3588 对应的
    COM 口；
•   设置上述串口参数后打开端口，复位或重新上电，即可看到系统启动日志；
•   需要观察 FPGA 侧打印时，切换到 FPGA 对应的 COM 口即可。

    【排错】若打开串口后无任何输出，请依次检查：电源是否已打开（S1 是否在 ON）、
    USB_Debug 线缆是否为数据线（而非纯充电线）、COM 口是否选错、波特率是否与固件一致。

  LV60PG484A（U10）之间并非只靠一根总线相连，而是同时存在 4 条用途不同的链路，外加 1 条

  2.3.2 PCIe 3.0 ×2 高速链路

       这条链路承担两颗芯片之间的高带宽数据通道，也是本板最有价值的部分：RK3588 的 PCIe
  3.0 控制器（PCIE30_PORT0，配置为 ×2）作为 Root Complex，FPGA 的 2 路 SerDes 硬核（MGT0、
  MGT1）作为 Endpoint。

  （1）电路说明

  •    交流耦合：4 对差分线各自串入 2 只 0.1 µF 电容（共 8 只），用于隔开两端不同的共模电平，
       符合 PCIe 规范的 AC 耦合要求，同时也让 FPGA 侧可以自由设定 SerDes 的共模电压。
  •    收发交叉：RK3588 的发送对（TX）接 FPGA 的接收对（MGT_RX），RK3588 的接收对（RX）
       接 FPGA 的发送对（MGT_TX）。这个交叉关系在 PCB 上已经固定，无法通过配置反转。
  •    参考时钟：由 RK3588 的 E33 / E34 输出 100 MHz 差分时钟（MGT_CLK0），直流耦合直接送
       入 FPGA 的 F6 / E6，并在 FPGA 侧并联 R126（100 Ω）做差分端接；R58 为同值备位，默认不
       贴装。
  •    另一路时钟：FPGA 的 MGT_CLK1（F10 / E10）不来自 RK3588，而是经板对板连接器 P5 从底
       板引入，供 SFP 使用（对应的 125 MHz 时钟源默认不贴装），不属于本条链路。

  （2）管脚与信号对应

2.3.3 RGMII 千兆以太网链路（GMAC1 与 Bank B2）

    这条链路上没有独立的以太网 PHY 芯片——FPGA 直接扮演了 RK3588 的 PHY 角色。因此使
用时需要在两侧各做一件事：RK3588 侧用 GMAC1 控制器（RGMII 模式）驱动，FPGA 侧自行实
现 RGMII 接口逻辑。

（1）电路说明

•   信号构成：12 根 RGMII 信号、2 根 MDC/MDIO、1 根 25 MHz 参考时钟信号。
•   连接方式：两侧直连，板上既没有串阻、也没有电平转换器。RGMII 本身的电平由
    RK_VCCIO5（RK3588 GPIO3 域的 IO 电源）与 FPGA 的 VCCIO2（Bank B2 的 IO 电源）决定，
    使用前请确认两者一致。

2.3.5 FSPI 复用链路（默认给 eMMC）

    RK3588 的 SDMMC / eMMC 控制器引脚同时复用了 FSPI 功能。核心板为这 6 个引脚各准备了
两个 0 Ω 电阻位，通过贴装哪一侧来决定这组引脚归谁使用。

（1）电路说明

•   默认通路：R5 ~ R10（0 Ω，出厂贴装）→ 接板载 eMMC（U5），RK3588 由此从 eMMC 启动。
•   备用通路：R16 ~ R21（0 Ω / DNI，出厂不贴装）→ 接 FPGA Bank B2。把这 6 只贴上、同时去
    掉 R5 ~ R10，这组引脚即交由 FPGA 以 FSPI 方式使用。
•   切换方式：板上没有模拟开关或多路复用器，因此切换只能通过改板焊接实现，软件无法切换。

【第四部分】开发与调试

4.1 FPGA 开发流程（Gowin EDA）

     GW5AT-60K 使用高云官方的 Gowin EDA（云源软件）进行开发，基本流程如下：

•    新建工程，器件选择 GW5AT-LV60PG484A（注意选择正确的速度等级与封装）；
•    编写 RTL 代码（Verilog / VHDL）或使用 IP Core Generator 生成 IP；
•    编写物理约束文件（.cst），把设计端口绑定到本手册附录中给出的 FPGA IO 名称（形如
     IOT144A/LVDS/DQ3、IOB130A/LVDS 等）；
•    综合（Synthesize）→ 布局布线（Place & Route）→ 生成比特流（.fs）；
•    通过 Gowin Programmer 连接板上 USB-JTAG（J2 口）或外部 JTAG（P8）下载到 FPGA 内部
     SRAM；
•    需要固化时，把比特流写入配置 Flash（U13，W25Q128JVSIQ）。
    【重要】由于本板采用“SoC + FPGA”结构，FPGA 工程中的时钟资源主要来自：CLK_50MHz
    （50MHz 有源晶振）、PL_CLK_P/N（200MHz 差分）、以及由 RK3588 提供的 MGT_CLK0
    （100MHz，用于收发器）。PL 端可用 PLL 最多 8 个。

4.3 RK3588 侧开发与固件烧录

     RK3588 侧的开发与常见的 Rockchip 平台一致：

•    使用官方 Linux SDK 编译 U-Boot、Kernel、Rootfs；
•    常用调试手段：串口控制台、ADB / SSH、以及通过 Type-C 或 USB 的固件烧写；
•    烧写工具：Rockchip 的 RKDevTool（Windows）或 upgrade_tool（Linux）；
•    PCIe、USB、HDMI、MIPI 等接口的设备树配置需与板上实际连接一致，特别是 PCIe 控制器与
